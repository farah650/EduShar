# EduShare Frontend (Minimal Template)

## Quick start

1. Install dependencies:
```bash
npm install
```

2. Set your backend URL:
- Edit `src/api/axiosConfig.js` and change `baseURL` to your backend (e.g. http://localhost:8081).

3. Run dev server:
```bash
npm run dev
```

This template includes example API wrappers in `src/api/` that map to your provided endpoints.
